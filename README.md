# Inspireshift Technologies Site

## Local Development
- Double-click `index.html` to view directly in any modern browser.
- Or run a static dev server: `npx -y serve .` from inside `/inspireshift-site`.

## Web3Forms Contact Form Key
- Open `js/form.js` and update `const WEB3FORMS_KEY = "YOUR_ACCESS_KEY";` with your access key from https://web3forms.com.

## Free Deployment
- **Netlify / Vercel**: Drag & drop the `/inspireshift-site` folder or connect GitHub repo (Build command: None, Output directory: `.`).
- **GitHub Pages**: Push files to a repository, go to Settings > Pages, and select Branch: `main` / `root`.
